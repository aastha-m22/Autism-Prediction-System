#  Autism Detection Using Machine Learning

##  Overview

This project focuses on predicting the likelihood of Autism Spectrum Disorder (ASD) using machine learning techniques. The goal is to assist in early screening by analyzing behavioral and personal attributes.

Autism is a developmental condition that affects communication and behavior. Early detection can significantly improve outcomes, and this project explores how data-driven approaches can support that process.

---

##  Features

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Feature selection and transformation
* Machine Learning model training
* Model evaluation and comparison
* Prediction system for new inputs

---

##  Tech Stack

* **Python**
* **Pandas, NumPy** (Data Handling)
* **Matplotlib, Seaborn** (Visualization)
* **Scikit-learn** (ML Models)

---

##  Dataset

The dataset contains behavioral screening data and personal attributes such as:

* Age
* Gender
* Family history
* Behavioral scores

> Dataset used: Autism Screening Dataset (can be from Kaggle or similar sources)

##  How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/autism-detection.git
```

2. Navigate to the project folder:

```bash
cd autism-detection
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the notebook or script:

```bash
python main.py
```
